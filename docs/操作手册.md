# DT-01 操作手册

> 面向现场操作者：从上电到巡线的完整操作流程、每个按钮的作用、急停手段与故障处理。

---

## 1. 上电与遥控器（每次开机必读）

遥控器为富斯 6 通道（白色），**开机前四个拨杆全部拨到最上**：

| 拨杆 | 位置 | 含义 |
|---|---|---|
| SWB | **中间** | 串口控制（GUI/巡线可动车）——**日常作业必须停在这里** |
| SWB | 下方 | 纯遥控模式（GUI 指令被屏蔽） |
| SWD | 上/下 | **急停 / 解除**（硬件级，最可靠的停车手段） |

上电顺序：遥控器开 → 底盘电源 → 工控机。

## 2. 上位机准备（一次性）

1. **免密登录工控机**：
   ```bash
   ssh-keygen -t ed25519
   ssh-copy-id teamhd@192.168.2.153
   ```
2. **DDS 配置**：用 `robot_ws/src/dt01_bringup/config/cyclonedds.xml.template`
   生成 `~/cyclonedds.xml`（网卡填本机无线网卡名，Peer 填工控机 IP 192.168.2.153）
3. **环境变量**（写入 `~/.bashrc`）：
   ```bash
   export ROS_DOMAIN_ID=42
   export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
   export CYCLONEDDS_URI=file:///home/<你的用户名>/cyclonedds.xml
   ```
4. **ROS 包**：确认已装 `ros-humble-nav2-msgs`、`ros-humble-slam-toolbox`、
   `ros-humble-rmw-cyclonedds-cpp`（缺了 GUI 会静默失败）
5. 上位机与工控机连**同一 WiFi 网段**

## 3. 启动与主界面

```bash
cd gui && bash run.sh
```

| 按钮 | 作用 |
|---|---|
| 启动机器人 | SSH 在工控机启动整套系统（驱动+雷达+IMU+安全层）。若车上已在跑则直接"接管"，不重启 |
| 建图模式 | 启动 SLAM，开始建图 |
| 导航模式 | 启动/切换导航栈（需已选地图）。切换地图时强制重启换图（预热 30~60s） |
| 断开连接 | 杀掉工控机上**全部**机器人进程并复查（彻底重置用） |
| ⛔ E-STOP | 全局急停（=键盘 X） |

连上工控机的标志：右侧网络显示"已连接工控机"，地图自动从车上同步下来。

## 4. 建图流程

1. 启动机器人 → 建图模式
2. 用遥控开车绕场：**速度 ≤0.3 m/s，走闭合回路**（回环检测需要重访）
3. 建完点「💾 另存地图」→ 输入名字 → 自动存到工控机并镜像回本地
4. 退出建图模式时如提示保存，先保存再退出

## 5. 导航巡线流程（日常主流程）

1. 「导航模式」（首次会重启导航栈，等 30~60s 预热）
2. 等待定位：GUI 会自动用该地图保存的初始位姿定位，并在 1.5s 后用
   **激光-地图匹配自动精修**（只需"指个大概"，无需点得很准）；
   若激光贴图左右反（对称环境 AMCL 镜像解，日志会告警），重新「设定初始位姿」
   （**车头朝向必须指对**）或点「全局定位」
3. （可选）「＋禁区」画**电子围栏**：地图上左键逐点添加、右键闭合（≥3 点）。
   禁区内的打点会被拒绝，巡线中目标点进禁区会自动停车；
   「清空禁区」一键删除当前地图全部禁区
4. 「＋打点」→ 在地图**白色空闲区域**依次点击（可拖动设朝向），
   相邻点自动连成青色路线；障碍/图外/禁区内点击会被自动拒绝
5. 「▶ 开始导航」：机器人先原地转向对正下一点，再沿连线直线行驶；
   状态栏显示"第X点 原地对正中 / 直线行驶剩余X米 / 绕行中"
6. 随时「■ 停止导航」停车清队列

打点建议：点间距 ≥0.5m；转弯处多打一个过渡点，别让两段线穿过障碍。

## 6. 急停手段（按可靠性排序）

| 手段 | 场景 |
|---|---|
| 遥控器 SWD 拨急停 | **任何时候**，硬件级，优先一切 |
| 键盘 `X` / 顶栏 E-STOP | GUI 可用时，取消导航+清队列+零速 |
| 「停止导航」按钮 | 结束巡线任务 |
| 拔底盘电源 | 最后手段 |

## 7. 巡线参数现场调优

**推荐：GUI 右侧「调参」标签页**——改数值 → 点该行「设」→ 通过 SSH 在工控机
执行 `ros2 param set`，**即时生效、无需重启**。每个参数的含义与"什么现象调它"
见 [docs/调参手册.md](调参手册.md)（含常规 / 避障 / 导航三组参数与故障速查表）。

不用面板时也可在工控机上手动执行：

```bash
ros2 param set /route_follower v_max 0.25     # 太快就降
ros2 param set /route_follower kp_rot 2.0     # 原地转向太慢加大
ros2 param set /route_follower min_w 0.18     # 原地转不动（静摩擦大）加大
ros2 param set /route_follower look_ahead 0.4 # 走线抖动就减小前视
```

⚠ 面板 / 命令行改的都是**运行时参数**，重启导航栈后回默认值；
调好后要固化到源文件（方法见调参手册第一节），调参纪律见调参手册第七节。

## 8. 常见故障

| 现象 | 原因与处理 |
|---|---|
| 点「启动机器人」没反应/超时 | 免密登录没配好；`ssh teamhd@192.168.2.153` 手动测 |
| 界面连上了但车不动 | 遥控器 SWB 不在中间档；急停 SWD 未解除 |
| 激光贴图左右反 | AMCL 镜像解（见第 5 节步骤 2）；日志有告警 |
| 切图后定位乱 | 已改为强制重启换图，等预热后重新定位 |
| 巡线没反应 | 日志搜"巡线节点"；工控机看 `/tmp/dt01_route_follower.log` |
| 原地转向不动 | `min_w` 太小，现场调参（见第 7 节） |
| 一打开 GUI 就有数据 | 车上有上次残留孤儿进程，点「断开连接」清理 |
| 任务结束显示部分到达 | 日志会写超时/失败被跳过的点；多为定位翻面或路线上有临时障碍 |
| 巡线中突然停车不动 | 日志搜"电子围栏"（目标点进了禁区，重新打点绕开）或"定位丢失" |
| 打点总被拒绝 | 点在障碍/图外/禁区内；检查是否误画了禁区（「清空禁区」可验证） |
