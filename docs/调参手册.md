# DJ-NAV 1.0 调参手册

> DT-01 差速底盘 · RK3588 工控机 · ROS 2 Humble
> 配套入口：GUI 右侧「调参」标签页
> 研发：fofomo

本手册回答三件事：**面板怎么用**、**每个参数是什么意思**、**出什么现象该调它**。

---

## 一、调参面板怎么用

1. 先「启动机器人」并进入**导航模式**（工控机上的巡线 / 导航节点必须已在运行）
2. 打开 GUI 右侧 **「调参」** 标签页
3. 改数值 → 点该行右侧 **「设」** → GUI 通过 SSH 到工控机执行 `ros2 param set` → **即时生效**
4. 结果看主日志区：
   - 成功：`调参：/route_follower avoid_far 已设置（Set parameter successful）`
   - 失败：`调参失败：/xxx yyy —— 原因`（常见：节点没起、参数不存在、SSH 不通）
5. 「恢复默认」只把面板数值还原，**不下发**，不会影响车上

### ⚠ 生效范围（务必先看）

面板改的是**运行时**参数，重启导航栈 / 巡线节点后会回到默认值。想长期生效需同步改源文件：

| 参数类别 | 固化位置 | 生效方式 |
|---|---|---|
| 常规 / 避障（`/route_follower`） | `gui/route_follower_node.py` 里 `declare_parameter` 的默认值 | GUI 点「开始导航」会自动比对 md5 并上传新脚本 |
| 导航（Nav2 各节点） | `robot_ws/src/dt01_bringup/config/nav2_params_real.yaml` | scp 到工控机 `~/dt01_ws/src/dt01_bringup/config/` 后**重启导航即可，不需要 colcon build**（symlink-install） |

## 二、三类参数的适用范围

| 分类 | 目标节点 | 影响 |
|---|---|---|
| **常规** | `/route_follower` | 巡线速度、追踪 / 对正增益、前视距离、到点判定 |
| **避障** | `/route_follower` | 分层绕障的触发距离、转向强度、前进速度、回线快慢 |
| **导航** | Nav2 各节点 | 自由规划速度、代价地图膨胀、AMCL 定位更新 |

⚠ **本系统核心模式是「打点连线巡线」，只受「常规」和「避障」两类影响。**
Nav2 的「导航」类参数只在 Nav2 自由规划时起作用；当前巡线模式下 Nav2 主要保留 **AMCL 定位**（所以导航类里最常用的是「定位」这一组）。

## 三、常规参数（`/route_follower`）

| 参数 | 默认 | 含义 | 调大 | 调小 | 什么时候改它 |
|---|---|---|---|---|---|
| `v_max` | 0.35 m/s | 直线行驶速度上限 | 跑得快，但超过 0.5 易引发定位跳变 / 车身抽搐 | 更稳，作业变慢 | 想提速（一次加 0.05，跑一段确认定位不飘）；定位不稳 / 抽搐就压回 |
| `w_max` | 0.80 rad/s | 转向角速度上限 | 转向更猛 | 转向更柔 | 转向太慢跟不上就调大；转向过猛甩头就调小 |
| `kp_rot` | 1.60 | 出发前**原地对正**下一点的比例增益 | 对正快，太大会转过头来回摆 | 对正慢，半天对不正 | 出发前原地转半天 / 转过头来回摆 |
| `kp_lat` | 2.20 | 直线行驶**贴合连线**的比例增益 | 贴线紧，太大会蛇形摆动 | 贴线松，跑偏拉不回来 | 走线蛇形摆动就调小；明显跑偏离连线就调大 |
| `min_w` | 0.12 rad/s | 克服底盘静摩擦的角速度下限 | 转向更有劲 | 转向更精细 | **原地转不动**（静摩擦卡住）→ 调大（如 0.20）；转向抽搐 → 调小 |
| `look_ahead` | 0.5 m | 前视点追踪的预瞄距离 | 切弯提前、容易走内圈 | 贴线更紧、但容易抖 | 走线抖动 → 调大；拐角处切内圈太多 → 调小 |
| `arrive_tol` | 0.15 m | 判定到达某个打点的距离 | 提前算到达 | 更精确，但可能在点上反复微调 | 到达后还在原地微转 → 调大；太早算到达就调小 |
| `goal_timeout` | 90 s | 单个打点最长执行时间 | 更耐心等 | 更快跳过 | 正常路段被跳过 → 调大；卡死太久占用任务 → 调小 |

## 四、避障参数（`/route_follower`）—— 分层绕障

先理解分层逻辑（2026-09-29 重写后的行为）：

```
前方障碍距离 front
  │
  > 1.5m (avoid_far)      → 安全区：纯巡线，全速，偏移慢回
  ├─ 1.0~1.5m             → 预警区：小角度转向(0.27→0.52 rad/s) + 几乎不减速 → 提前变道，丝滑切出
  ├─ 0.22~1.0m            → 近距区：满转向(0.8 rad/s) + 保持前进(不低于 v_turn_min) → 边转边走绕过去
  └─ ≤ 0.22m (stop_dist)  → 紧急区：满转向 + 蠕行(v_creep) → 低速继续绕（不再停车干转）
```

配套机制：
- **绕行侧记忆**：进入避障时锁定一侧（左 / 右），障碍彻底离开才释放——防止在障碍正中左右摇摆
- **回线弱化**：`recover_rate`=0.98 慢回，绕完由巡线自然导回，不急拉

| 参数 | 默认 | 含义 | 调大 | 调小 | 什么时候改它 |
|---|---|---|---|---|---|
| `avoid_far` | 1.5 m | 【预警区】前方障碍小于此距离就开始小角度提前变道 | 更早开始绕；**太大（如 3m）在窄走廊会一直偏离路线** | 退回"到眼前才躲" | 绕障太晚、总是贴到障碍才躲 → 调大；窄走廊一直绕来绕去 → 调小 |
| `avoid_near` | 1.0 m | 【近距区】小于此距离切换为**大幅转向 + 保持前进** | 更早进入大幅转向 | 更晚才猛转 | 想"提前 1m 就大幅转向"就是它；绕大障碍可加大到 1.5 |
| `stop_dist` | 0.22 m | 【紧急区】小于此距离切换为蠕行绕行 | 更早进入低速，更安全 | 更贴更激进 | 现场有行人 / 宠物 → 调大（更早低速）；空旷场地想利落 → 可略调小 |
| `avoid_w` | 0.8 rad/s | 避障转向的角速度上限 | 绕得更果断 | 车身摆动更小 | **绕不开**障碍 → 调大；绕障时车头摆动剧烈 → 调小 |
| `v_turn_min` | 0.15 m/s | 近距转向时的**最低前进速度**（保证边转边走） | 绕行推进更快 | 更谨慎；**设 0 会退化成原地干转，静态障碍永远绕不开** | 障碍前"只转不走"绕不开 → 确认它不是 0；想更激进绕 → 调到 0.20 |
| `v_creep` | 0.06 m/s | 紧急区（≤ stop_dist）的前进速度 | 继续蹭着绕 | **设 0 = 停车等待**（遇人挡路更安全） | 担心贴近行人 → 设为 0；确认场景无人 → 保持 0.06 |
| `avoid_off_max` | 0.8 m | 绕障时前视点横向偏移的最大值 | 能切更大的弧线，绕大障碍更从容 | 偏移小，绕行幅度保守 | 大障碍 / 长条障碍绕不出去 → 调大；绕行跑太偏 → 调小 |
| `recover_rate` | 0.98 | 障碍解除后偏移回落到线路的速率 | **越接近 1 回线越慢**（绕完慢慢回去） | 调小(0.92)会猛拉回线，可能**二次贴障** | 绕开后又被猛拉回去蹭到障碍 → 调大（0.99）；绕开后迟迟不回线 → 调小 |

## 五、导航参数（Nav2，仅自由规划 / AMCL 定位时相关）

### 5.1 运动控制 `/controller_server`

| 参数 | 默认 | 调大 | 调小 | 什么时候改 |
|---|---|---|---|---|
| `FollowPath.max_vel_x` | 0.55 m/s | 跑得快，太快定位跟不上 | 更稳 | 提速一次 +0.1，跑一段确认定位不飘 |
| `FollowPath.max_vel_theta` | 1.0 rad/s | 转向猛 | 转向柔 | 转向跟不上 / 过猛 |
| `FollowPath.acc_lim_x` | 0.8 m/s² | 起步猛，**易打滑（打滑 = 定位跳变源头）** | 起步柔和 | 起步 / 转向打滑、定位跳变 → 调小 |
| `general_goal_checker.xy_goal_tolerance` | 0.30 m | 提前算到达 | 更精确，但膨胀区可能把车挡在圈外 | 目标点靠近障碍时永远判不到到达 → 调大 |

### 5.2 代价地图 `/global_costmap`、`/local_costmap`

| 参数 | 默认 | 调大 | 调小 | 什么时候改 |
|---|---|---|---|---|
| `inflation_layer.inflation_radius` | 0.40 m | 更保守，离障碍远 | 敢贴墙，窄通道能过 | **窄通道规划不出路 / 过不去** → 调小；贴墙太近蹭到 → 调大 |
| `inflation_layer.cost_scaling_factor` | 6.0 | 越敢贴墙 | 越保守 | 规划太贴墙 → 调小；绕障过度绕远 → 调大 |

> 全局 = 规划全局路径时用；局部 = 实时避障的滚动窗口用。两者通常同步调整。

### 5.3 定位 `/amcl`

| 参数 | 默认 | 调大 | 调小 | 什么时候改 |
|---|---|---|---|---|
| `update_min_d` | 0.05 m | 粒子滞后于真实位姿 → **位姿跳变** | 更新更频繁，更跟手但耗 CPU | 走一段后位姿突然跳 → 确认它是 0.05（不要调大） |
| `update_min_a` | 0.05 rad | 原地转圈时 AMCL 不更新 → **丢定位** | 转一点就更新 | "原地转一下就丢定位" → 确认它是 0.05 |
| `max_beams` | 90 | 定位更稳 | 省 CPU | 定位不稳可调大；CPU 吃紧调小 |

## 六、故障 → 调参速查表

| 现象 | 先调这个 | 说明 |
|---|---|---|
| 到障碍眼前才开始躲 | `avoid_far` ↑ | 默认 1.5m；想更早绕调到 2.0 |
| 障碍前"只转不走"，绕不开 | `v_turn_min` | 确认不是 0（默认 0.15 m/s） |
| 绕障幅度太小、还是蹭到 | `avoid_w` ↑ / `avoid_off_max` ↑ | 转向更猛 + 偏移更大 |
| 绕开后又被拉回去蹭到 | `recover_rate` ↑ | 0.98 → 0.99，回线更慢 |
| 窄走廊里一直绕来绕去 | `avoid_far` ↓ | 3.0 → 1.2，别太早触发 |
| 原地转向不动 | `min_w` ↑ | 0.12 → 0.20 克服静摩擦 |
| 原地转向转过头来回摆 | `kp_rot` ↓ | 1.6 → 1.2 |
| 直线走蛇形摆动 | `kp_lat` ↓ | 2.2 → 1.6 |
| 明显跑偏、拉不回连线 | `kp_lat` ↑ / `look_ahead` ↑ | 贴线更紧 |
| 到达后还在原地微调 | `arrive_tol` ↑ | 0.15 → 0.25 |
| 定位跳变 / 车身抽搐 | `v_max` ↓ | 0.35 → 0.25，稳了再逐步放 |
| 起步打滑 | Nav2 `acc_lim_x` ↓ | 0.8 → 0.5 |
| 窄通道规划不出路 | Nav2 `inflation_radius` ↓ | 0.40 → 0.30 |
| 原地转一下就丢定位 | AMCL `update_min_a` | 确认为 0.05（不要调大） |
| 想提速 | `v_max`（巡线）/ `max_vel_x`（Nav2） | **一次加 0.05~0.1，跑一段确认定位不飘再加** |

## 七、调参纪律（真车经验）

1. **一次只改一个参数**，改完跑一段再看——同时改多个，出问题分不清是谁的锅
2. **每次改 ±20% 以内**，别一步到位
3. **提速必须先确认定位没飘**：`v_max` 每次 +0.05，跑一段看 AMCL 位姿是否平滑；一飘就退回
4. **改完记录**：面板改的是运行时值，重启就没了。验证有效后务必同步改源文件（见第一节）
5. **安全相关参数别激进**：`v_creep`（紧急区是否蠕行）、`stop_dist`（何时进入低速）涉及人身安全，现场有人的场景优先选保守值
6. 面板下发失败时先看日志：多数是**节点没起**（先进导航模式）或参数名写错
