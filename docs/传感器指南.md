# DT-01 传感器与硬件接口指南

> 每个传感器的接口、驱动、话题、参数与配置方法。
> 网络规划、串口映射、udev 规则都在这一篇。

---

## 1. 网络与串口规划（总表）

| 设备 | 接口 | 地址/设备名 | 关键参数 |
|---|---|---|---|
| DT-01 底盘 | 工控机 **COM1**（RS232 三针） | `/dev/ttyS7` | 115200 / 8N1 / 帧头 `ED DE` |
| 蓝海雷达 LDS-50C-E-R | 工控机 **eth0** 网口（UDP） | `192.168.158.98:6543` | ~15Hz |
| 飞迪 N100 IMU | USB（CP2102） | `/dev/dt01_imu`（udev 别名） | 400Hz |
| 超声 ×6 | 底盘板载，经串口聚合 | 话题 `sonar_*` | **仅 DT-01D 机型**，DT-01 标准版无 |
| 工控机 ↔ 上位机 | WiFi | 工控机 `192.168.2.153`，上位机同网段 | ROS_DOMAIN_ID=42 |

**工控机双网卡**：
- `enP2p33s0` = 192.168.2.153（与上位机通信网段）
- `eth0` = 192.168.158.15（雷达网段；**雷达是 .98，.15 是工控机自己**，别搞混）

## 2. 底盘（差速底盘协议驱动）

- **驱动包**：`robot_ws/src/dt_ros2/`（C++，`dt_control.cpp` 实现协议）
- **串口**：COM1 = `/dev/ttyS7`，115200 8N1，帧头 `ED DE`
- **接线坑**：RS232 必须**交叉接**——底盘 TX → 工控机 RX；直连表现为零响应
- **话题**：
  - 订阅：`/cmd_vel`（safety_mux 输出）
  - 发布：`/odom`（经 EKF 后 50Hz）、`/battery_state`、`/dt01/chassis_status`
- **消息定义**：`robot_ws/src/robot_ros2_msgs/`（底盘速度/电量/错误码等）
- **协议文档**：随底盘厂家资料提供，本仓库不含

## 3. 激光雷达（蓝海 LDS-50C-E-R）

- **驱动包**：`robot_ws/src/bluesea2/`（厂家提供，节点 `bluesea2_node`）
- **配置**：`dt01_bringup/config/udp_lidar.yaml`（UDP 模式，端口 6543）
- **注意事项**：
  - 雷达必须在 `192.168.158.x` 网段，工控机 eth0 静态配 `192.168.158.15`
  - 安装朝向由 URDF TF 描述（`dt01_bringup/urdf/dt01_real.urdf.xacro`），
    GUI 画激光点按 `map→base_scan` TF 换算，改安装角度只改 URDF
  - 编译路径必须纯英文无空格（该驱动在中文路径下编译失败）

## 4. IMU（飞迪 N100）

- **驱动包**：`robot_ws/src/fdilink_ahrs/`（厂家提供）
- **串口别名**：UDEV 规则映射为 `/dev/dt01_imu`（运行
  `dt01_bringup/scripts/setup_udev.sh` 安装，避免 USB 序号漂移）
- **数据链**：400Hz 原始 → `imu_preprocess.py` 降采样 + 陀螺零偏扣除 →
  EKF 融合 → `/odom` 50Hz
- **必须标定**：`imu_preprocess.py` 的 `gyro_bias_z`（静止 20s 取 wz 均值）。
  零偏不扣 → yaw 匀速漂移 → 建图扇形重影、巡线方向漂

## 5. 超声波（仅 DT-01D 机型）

> **机型差异说明**：6 路超声是 DT-01D（机场双前置雷达方案）的配置。
> **当前 DT-01 标准版（顶部单雷达）没有超声硬件**——GUI 传感器面板中
> 超声显示"未接入"属正常，近距防撞完全由激光雷达承担（safety_mux）。

DT-01D 机型上：

- 底盘板载，数据经底盘串口聚合，由 dt_ros2 发布
- 话题：`/sonar_fl` `/sonar_fr` `/sonar_sl` `/sonar_sr` `/sonar_rl` `/sonar_rr`
  （前左/前右/左/右/后左/后右）
- 类型 `sensor_msgs/Range`，参与 safety_mux 近距防撞与 GUI 避障分析

## 6. 急停（遥控器接收机）

- 富斯 6 通道遥控器，接收机接入底盘急停回路
- SWD：硬件级急停/解除（优先一切软件指令）
- SWB：中间档 = 串口控制使能；下方 = 屏蔽串口（纯遥控）
- 遥控速度指令走 `/cmd_vel_teleop`，由 safety_mux 限速透传

## 7. 部署与编译

```bash
# 工控机（Ubuntu 22.04 + ROS 2 Humble）
cd ~/dt01_ws/src           # 放入 robot_ws/src 下的全部包
colcon build
source install/setup.bash

# 一键环境脚本（DDS/NTP/udev/自检）
bash dt01_bringup/scripts/setup_dds.sh     # DDS 环境变量
bash dt01_bringup/scripts/setup_ntp.sh     # 双机时间同步（TF 对时间戳敏感）
bash dt01_bringup/scripts/setup_udev.sh    # 串口 udev 别名
bash dt01_bringup/scripts/check_system.py  # 系统自检

# 整机启动（驱动+安全层+建图或导航）
ros2 launch dt01_bringup dt01_all.launch.py mode:=idle          # 只起本体
ros2 launch dt01_bringup dt01_all.launch.py mode:=slam          # 建图
ros2 launch dt01_bringup dt01_all.launch.py mode:=nav \
    map_file:=/home/<user>/dt01_maps/<地图名>.yaml               # 导航
```

> 注：launch 示例与 `nav2_params_real.yaml` 中的路径默认按工控机用户
> `teamhd` 的家目录书写；更换用户名/路径时同步修改（含
> `default_nav_to_pose_bt_xml` 一行）。
