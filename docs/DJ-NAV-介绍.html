ARCHITECTURE

真车安全架构

GUI 跑在笔记本上，本身不启动任何 ROS 进程：驱动、雷达、IMU、 安全层、建图/导航全部通过 SSH 在工控机上启停，GUI 只做监控与下发。 即使笔记本断网或崩溃，机器人也会安全停车。

ROUTE PATROL

打点连线巡线 —— 核心工作模式

不再让导航算法自由规划路径。你在地图上打几个点，相邻点自动连成 最短直线，机器人严格沿这条线行驶；控制算法跑在工控机上的独立节点里， 笔记本断网 2 秒内自动停车。

1

打点连线

地图上依次点击，相邻点自动连成最短直线，实时显示剩余路线，走过的段自动消失。

2

先对正，再出发

每段出发前原地转向对正下一点（偏差 <3.4° 才动车），绝不在到点后磨蹭调头。

3

严格走线

Pure Pursuit 前视点追踪，横向跑偏被自动拉回画出的线，其他地方一律不走。

4

分层绕障

前方 1.5m 内提前小角度变道 → 1.0m 内大幅转向边转边走 → 0.22m 内低速蠕行，全程不在障碍前停车干转，解除后自动回线。

巡线参数默认值说明（可 ros2 param 在线调）
v_max0.35 m/s巡线速度，跟随 GUI 滑块，上限 0.5
k p_rot / kp_lat1.6 / 2.2原地对正 / 直线追踪 增益
min_w0.12 rad/s克服底盘静摩擦的最小转向速率
avoid_far / avoid_near / stop_dist1.5 / 1.0 / 0.22 m分层绕障的预警 / 近距 / 紧急边界
v_turn_min / v_creep0.15 / 0.06 m/s近距最低前进 / 紧急蠕行速度（v_creep=0 即停车等待）
goal_timeout90 s单点超时自动跳过，继续后续点
hb_timeout2.0 sGUI 心跳超时，断链自动停车
FEATURES

全部功能

不止巡线 —— 从建图到监控到诊断，真机作业的完整工具链。

🗺️

建图作业

一键启动 SLAM，遥控绕场建图（≤0.3 m/s 走闭合回路）；「另存地图」保存到工控机并自动镜像回本地，保存前确认 SLAM 在跑，杜绝静默丢图。

🧭

导航定位

AMCL 定位三件套：自动初始位姿（按地图保存复用）、手动点选拖朝向、全局定位粒子重搜。点选后激光-地图匹配自动精修，指个大概即可；附翻面检测，对称环境激光贴图左右反时主动告警。

🎮

手动遥控

界面按钮 + 全局键盘 WASD（焦点在哪儿都生效，打字自动让路）；线速度 0.05~1.0 m/s / 角速度 0.1~2.0 rad/s 滑块实时调；经安全层限速透传。

📡

传感器监控

雷达实时叠加地图（TF 自动纠正安装偏转）、IMU 状态；8 方位障碍分析给出驾驶建议（"前方受阻，左侧畅通 → 建议左转绕行"）。超声 ×6 为 DT-01D 机型配置（标准版无此硬件，面板显示未接入属正常）。面板可弹出独立窗口。

🔋

状态监控

电量（电压/百分比/充放状态）、底盘心跳（模式/速度/急停标志/错误码）、网络状态、实时速度——提到面板最顶部，开车时一眼可见。

🗂️

多地图管理

首次连通自动同步工控机地图到本地镜像；初始位姿按地图分别保存、长期复用；切图强制重启导航栈换图，防止新旧图坐标系错位。

🚧

电子围栏

地图上画禁区多边形（左键加点、右键闭合），按地图持久化并下发给巡线节点：禁区内打点被拒绝、路线点自动过滤、巡线中目标进禁区立即停车。

🎛️

调参面板

右侧「调参」标签把常规 / 避障 / 导航三类最常用参数集中一处，改数值点「设」即通过 SSH ros2 param set 即时生效，无需重启导航栈；配套调参手册与故障速查表。

📋

日志系统

显示截断但内部保留完整原文，「复制全部」拿到未截断内容；复制/选中复制/清空/放大还原，日志区高度自动记忆。

🔍

链路诊断

只认"最近 3 秒有没有真数据"，不信"话题存在"；启动预热自动重查不误报；连不上给按序排查清单；SSH 慢命令与等锁时间自动记录。

🔁

启停管理

「启动机器人」带接管探测（车上在跑就不重启，防丢图防双进程）；「断开连接」优雅停→强杀→杀完复查；孤儿进程自动探测提醒清理。

SAFETY

六层安全防护

真车第一。每一层都独立生效，任何一层都可以把车停下来。

防护层机制
底盘仲裁全部运动指令经 safety_mux：急停 / 防撞 / 激光急停常生效。巡线走 /cmd_vel_nav、遥控走 /cmd_vel_teleop，绝不直发 /cmd_vel
断链保护GUI 以 2Hz 发心跳，工控机侧节点 2 秒收不到 → 自动零速停车（WiFi 断、GUI 崩溃均覆盖）
全局急停顶栏红色 E-STOP 或键盘 X：取消导航 + 清空队列 + 立即零速，任何时刻可用
定位翻面检测设初始位姿 4s 后核对 AMCL：跳走 >0.6m 或翻转 >60° 立即告警（对称环境镜像解）
切图防护切换地图强制重启导航栈换图，杜绝"车按旧图匹配、人按新图打点"的坐标系错位
打点防护地图外 / 障碍 / 未知区域 / 禁区（电子围栏）内的点击自动拒绝，从源头避免不可达目标

FAQ

常见问题

Q：激光贴图左右反了？

长走廊等对称环境下 AMCL 收敛到镜像解。重新「设定初始位姿」（车头朝向指对）或点「全局定位」，日志会主动提示翻面告警。

Q：切换地图后定位乱？

切图会强制重启车上导航栈换图（约 30~60s 预热），预热完成后再定位即可。

Q：点了开始导航但机器人不动？

看日志是否有"巡线节点无回报"：查工控机 /tmp/dt01_route_follower.log；确认初始位姿已设定、地图上无红色翻面告警。

Q：巡线时原地转向不动 / 太猛？

在线调参：min_w 加大（转不动）或 kp_rot 减小（太猛），无需重启。
