## 一、这是什么

DJ-NAV 1.0 是跑在**上位机（笔记本）**上的 DT-01 真机导航控制台（PyQt5）。
它本身不跑任何 ROS 进程——驱动、雷达、IMU、EKF、安全层、建图/导航全部通过
**SSH 在工控机上启停**，GUI 只通过 DDS 网络做**监控与下发**：

```
上位机（笔记本）                       工控机（RK3588, teamhd@192.168.2.153）
┌─────────────────────┐   SSH 启停    ┌──────────────────────────────────┐
│  DJ-NAV GUI          │ ───────────▶ │  dt01_all.launch.py               │
│  · 地图显示/打点      │              │   ├ 底盘驱动 dt_ros2 (/dev/ttyS7) │
│  · 遥控 WASD          │              │   ├ 蓝海雷达 bluesea2 (UDP)       │
│  · 状态监控/日志       │ ◀─────────── │   ├ IMU 飞迪 N100 (400Hz)         │
└─────────────────────┘   DDS 数据    │   ├ EKF + safety_mux 安全层       │
         │  下发路线/心跳/急停          │   ├ slam_toolbox 建图             │
         └──────────────────────────▶ │   ├ Nav2 (AMCL 定位)              │
                                      │   └ route_follower 巡线节点        │
                                      └──────────────────────────────────┘
```

## 三、打点连线巡线（核心模式）

不再让导航算法自由规划路径，机器人**严格沿画出的路线**行驶：

| 步骤 | 行为 |
|---|---|
| ① 打点 | 地图上依次点击，相邻点**自动连成最短直线**（青色粗线实时显示） |
| ② 对正 | 每段出发前**先原地转向**对正下一点方向（偏差 <3.4° 才动） |
| ③ 走线 | Pure Pursuit 前视点追踪，横向跑偏自动拉回画出的线 |
| ④ 避障 | 分层绕障：1.5m 内提前小角度变道 → 1.0m 内大幅转向**边转边走** → 0.22m 内蠕行绕行，解除后自动回线（不停车干转） |

- 控制算法在**工控机上的独立节点** `route_follower` 中闭环（20Hz）：
  GUI 首次点「开始导航」会自动比对 md5、上传并启动该节点，之后复用。
- 多点队列自动顺序执行：到点即停车进入下一段对正，单点 90s 超时自动跳过，
  结束后按实际到达数汇报（不虚报"全部完成"）。
- 巡线时手动遥控被自动屏蔽，避免指令打架；Nav2 保留 AMCL 定位，不再自由规划。

**巡线参数**（可在工控机上 `ros2 param set /route_follower <名> <值>` 在线调）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `v_max` | 0.35 | 最大线速度 m/s（跟随 GUI 线速度滑块，上限 0.5） |
| `w_max` | 0.80 | 最大角速度 rad/s |
| `kp_rot` | 1.6 | 原地对正 P 增益 |
| `kp_lat` | 2.2 | 直线追踪 P 增益 |
| `min_w` | 0.12 | 克服底盘静摩擦的最小角速度 rad/s |
| `look_ahead` | 0.5 | 前视距离 m |
| `arrive_tol` | 0.15 | 到点判定半径 m |
| `avoid_far` / `avoid_near` / `stop_dist` | 1.5 / 1.0 / 0.22 | 分层绕障的预警 / 近距 / 紧急边界 m |
| `v_turn_min` / `v_creep` | 0.15 / 0.06 | 近距最低前进 / 紧急蠕行速度 m/s（v_creep=0 即停车等待） |
| `goal_timeout` | 90 | 单点超时（跳过该点继续）s |
| `hb_timeout` | 2.0 | GUI 心跳超时（断链停车）s |

以上参数均可在右侧「调参」标签页在线调（SSH 即时生效），
完整释义见 [docs/调参手册.md](../docs/调参手册.md)。

**电子围栏**：「＋禁区」进入绘制模式，左键逐点添加、右键闭合（≥3 点）。
禁区按地图持久化到 `config/keepout_zones.json`，随路线包下发给巡线节点：
禁区内打点直接拒绝，节点再过滤路线点、巡线中目标进禁区自动停车（双保险）。
「清空禁区」删除当前地图全部禁区。

## 四、建图作业

1. 「启动机器人」（SSH 启动工控机整套系统）→「建图模式」（启动 slam_toolbox）
2. 遥控绕场：速度 ≤0.3 m/s、走闭合回路（建图质量决定导航质量）
3. 「💾 另存地图」：输入名字 → 保存到工控机 `~/dt01_maps/<名字>/` →
   自动 scp 镜像回本地 → 下拉框自动刷新
4. 保存前自动确认 SLAM 确实在跑，避免"保存静默失败丢图"

## 五、导航定位与安全防护

### 定位工具
- **自动初始位姿**：进导航模式 12s 后自动用该地图保存的位姿定位
  （机器人每次出生点固定时，一次保存长期复用）
- **手动设定**：地图上点击并拖动设朝向，自动保存供下次复用
- **自动精修**：设定初始位姿 1.5s 后自动做激光-地图匹配
  （±1.2m/±50° 范围由粗到细搜索修正，`dj_nav/pose_refiner.py`）——
  用户只需"指个大概"，点选误差被自动消除
- **全局定位**：AMCL 大范围撒粒子自动搜索（位置完全未知时的兜底）
- **翻面检测**：设定位姿 4s 后核对 AMCL，跳走 >0.6m 或翻转 >60° 立即告警
  （长走廊等对称环境的镜像解，激光贴图左右反的根因）

### 六层安全防护

| 层 | 机制 |
|---|---|
| 底盘层 | 全部运动指令经 **safety_mux** 仲裁（急停/防撞/激光急停常生效）；巡线走 `/cmd_vel_nav`、遥控走 `/cmd_vel_teleop`，**绝不直发 `/cmd_vel`** |
| 断链保护 | 巡线时 GUI 以 2Hz 发心跳，**节点 2s 收不到 → 自动零速停车**（WiFi 断/GUI 崩溃均覆盖） |
| 全局急停 | 顶栏红色 `⛔ E-STOP` 或键盘 `X`：取消导航 + 清队列 + 零速，任何时刻可用 |
| 定位防护 | 翻面检测告警（见上） |
| 切图防护 | 切换地图**强制重启**车上导航栈换图，杜绝"车按旧图匹配、人按新图打点"的坐标系错位 |
| 打点防护 | 图外/障碍/未知区域/禁区（电子围栏）内点击自动拒绝，从源头避免不可达目标 |

## 六、其他功能

### 手动遥控
- 界面方向按钮 + **全局键盘** `W/A/S/D`（应用级事件过滤，焦点在哪儿都生效，
  打字时自动让路）；`X` = 急停
- 线速度 0.05~1.00 m/s、角速度 0.10~2.00 rad/s 滑块实时可调
- 遥控走 `/cmd_vel_teleop` 经 safety_mux **限速透传**，急停/防撞不失效
- 巡线进行中遥控自动屏蔽并提示

### 传感器监控页（右侧「传感器」标签）
- 雷达扫描实时叠加地图（用 TF 雷达帧换算，自动纠正安装偏转）
- IMU 实时状态与量程（超声/RGB-D 仅 DT-01D 机型配备，标准版显示"未接入"属正常）
- **8 方位障碍分析**：导航决策、避障决策、停车原因、下一步建议
  （例如"前方 0.45m 受阻，左侧畅通 → 建议左转绕行"）
- 面板可一键弹出为独立窗口，边看地图边盯传感器

### 状态监控（控制页最顶部）
- 电量（电压/百分比/充放状态）、底盘心跳（模式/速度/急停标志/错误码）、
  网络状态、实时速度——开车时一眼可见，不用滚动寻找

### 日志系统
- 显示截断超长行但内部保留**完整原文**，「复制全部」拿到的是未截断内容
- 复制全部 / 复制选中 / 清空 / 放大还原；日志区高度自动记忆，下次启动保持

### 链路诊断
- **真数据检测**：不看"话题存在"，只认"最近 3 秒 /odom、/scan 有没有数据"——
  杜绝"DDS 发现通了但数据不通"的假连接
- 启动预热自动重查（EKF/驱动就绪要 5~15s），不误报"连不上"
- 连不上时给出按顺序的排查清单；SSH 慢命令、等锁时间自动记录便于定位是
  GUI 内部排队还是链路问题

### 机器人启停管理
- 「启动机器人」：SSH 启动 + **接管探测**（车上已在跑就不重启，
  避免丢掉未保存的建图/双进程打架）
- 「断开连接」：优雅停 → 强杀兜底 → **杀完复查**，残留进程如实上报
- 关窗时同步等待停机完成（后台线程停机已被证明会留下孤儿进程）
- 孤儿进程自动探测：launch 死了但雷达/底盘还在发数据时主动提醒清理

## 七、多地图管理

- 首次连通工控机后**自动同步**车上地图到本地镜像（缺哪张拉哪张）
- 「刷新」手动重新同步；本地与工控机双份存储，导航用工控机那份
- 切换地图强制重启导航栈（30~60s 预热），防止新旧图坐标系错位
- 初始位姿按地图分别保存（`maps/saved/<图>/initial_pose.json`）

## 八、快速上手

```bash
# 前置（一次性）：
#   ssh-keygen -t ed25519 && ssh-copy-id teamhd@192.168.2.153
#   工控机 ~/cyclonedds.xml 的 Peer 指向上位机 IP

bash run.sh
```

操作顺序：**启动机器人 → （建图模式 → 另存地图）→ 导航模式 → 等定位 → 设初始位姿 → 打点 → 开始导航**。

- 手动遥控：界面按钮或键盘 `W/A/S/D`，`X` 急停
- 长走廊等对称环境若出现"激光贴图左右反"：重新「设定初始位姿」（车头朝向指对）
  或点「全局定位」，听到翻面告警按提示处理

## 十一、与原版（01-simulation 仿真版）的差异

仿真功能（Gazebo / 车型与世界选择 / 本机 SLAM·Nav2 进程）全部移除，仅保留真机工作方式。

### 修复（P0）
1. **主线程 SSH 全部后台化**：另存地图、孤儿进程探测、保存轮询等原来在主线程
   同步执行（界面卡死、与其它 SSH 抢锁），现全部走 `_remote_task` 后台线程。
2. **按钮语义**：连上工控机后主按钮固定显示「停止机器人」。

### 改进（P1）
3. **全局急停** `⛔ E-STOP`（X 键等效）。
4. **顶栏减负**：地图三件套移入右侧「控制」页顶部。
5. **状态监控提升**：电量/速度/网络提到面板最上面。

### 巡线（2026-09-28）
6. 打点连线巡线模式（见第三节），替代 Nav2 自由规划。
7. 切换地图强制重启导航栈（修复切图后定位坐标系错位）。
8. 初始位姿"翻面"主动检测告警。

### 巡线增强与调参（2026-09-29/30）
9. **分层绕障**重写：预警变道 → 近距边转边走 → 紧急蠕行，不再障碍前停车干转。
10. **电子围栏**：地图画禁区多边形，打点拦截 + 路线点过滤 + 巡线实时校验。
11. **调参面板**：右侧「调参」标签，常规/避障/导航参数 SSH 在线调即时生效。
12. **初始位姿自动精修**：激光-地图匹配自动修正手动点选误差（`pose_refiner.py`）。

## 十二、常见问题

| 现象 | 处理 |
|---|---|
| 激光贴图左右反 | 重新「设定初始位姿」（朝向指对）或「全局定位」；日志会有翻面告警 |
| 切图后定位乱 | 正常现象已修复为强制重启；等预热 30~60s 后重新定位 |
| 巡线没反应 | 看日志是否有"巡线节点无回报"；查工控机 `/tmp/dt01_route_follower.log` |
| 原地转向不动/太猛 | `ros2 param set /route_follower min_w 0.2`（加大）或 `kp_rot 1.2`（减小） |
| 停止后车还动 | 按急停 E-STOP；检查遥控器 SWB 是否在中间档（串口控制位） |
| 一打开 GUI 就有数据 | 车上有上次残留的孤儿进程，点「断开连接」清理后再启动 |
